First public release of **WorldClock**: an always-on-top world clock "island" that hides against the screen edge and drips out when your mouse touches it.

- 1-8 cities from 308, with sun/moon, twilight and bank holidays per region
- Liquid / Slide / None reveals, Dark or Liquid Glass style, optional glass effects
- Multi-monitor, tray menu, Start with Windows

**Install:** download `WorldClock-Setup-1.0.0.exe` and run it (per-user, no admin). Prefer no installer? Unzip `WorldClock-1.0.0-win64.zip` anywhere and run `WorldClock.exe`.

Windows 10/11, 64-bit. Note: the installer isn't code-signed, so SmartScreen may ask you to confirm ("More info" > "Run anyway").
